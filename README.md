# 灵眸 AI - Vision Studio

> 🎓 毕业设计项目 — 基于 OpenAI 视觉模型的 AI 智能图像理解平台

## ✨ 功能特色

- 💬 **视觉对话** — 上传图片与 AI 进行多轮深度对话，流式输出
- 🔬 **图像分析** — 6种分析模式：综合分析、物体识别、情感分析、色彩分析、故事猜测、技术评价
- ✍️ **创意写作** — 8种文学体裁：现代诗、短篇故事、俳句、歌词、影评、书信、日记、新闻稿
- 🔍 **图像对比** — 5种对比模式：找不同、找相同、全面对比、时间线推理、风格对比
- 📝 **文字提取** — OCR 智能识别印刷体、手写体、表格等
- ♿ **无障碍描述** — 3个级别的 WCAG 标准图片无障碍描述生成

## 🛠️ 技术栈

- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **样式方案**: Tailwind CSS 4
- **路由管理**: Vue Router 4
- **Markdown**: marked
- **AI 模型**: OpenAI GPT-4o Vision API

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📋 使用说明

1. 启动项目后，首先访问 **设置** 页面配置 OpenAI API Key
2. 支持自定义 API 地址（兼容 Azure OpenAI 等第三方代理）
3. 选择合适的模型（推荐 GPT-4o）
4. 开始使用各项 AI 视觉功能

## 🔒 安全说明

API Key 仅存储在浏览器本地 localStorage 中，不会发送到除配置的 API 服务器之外的任何第三方。
